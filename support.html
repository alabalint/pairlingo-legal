Gyakori kérdések

Kell fiók a használatához?
Nem, a PairLingo nem igényel regisztrációt vagy bejelentkezést.

Hogyan importálom a saját szavaimat?
A főképernyő ⬇️ ikonjával tölthetsz be egy CSV fájlt bármilyen nyelvpárban — a részletes formátumleírás a projekt GitHub oldalán található.

Szinkronizálódnak a szavaim a készülékeim között?
Igen, ha be van jelentkezve iCloud-fiókod, a szavak automatikusan szinkronizálódnak a saját, privát iCloud-tárhelyeden keresztül.

Frequently asked questions

Do I need an account to use it?
No, PairLingo doesn't require registration or sign-in.

How do I import my own words?
Use the ⬇️ icon on the main screen to load a CSV file in any language pair — the detailed format description is on the project's GitHub page.

Do my words sync across my devices?
Yes, if you're signed in to iCloud, your words automatically sync through your own private iCloud storage.
