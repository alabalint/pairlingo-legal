Feltöltés

Upload

A gomb a GitHub saját feltöltő felületére visz, ami kizárólag erre a custom-word-lists mappára van korlátozva — máshova a repóban nem tudsz vele írni. A fájlod egy Pull Requestként érkezik be, amit a fejlesztő átnéz, mielőtt megjelenne itt a letölthetők között.

Szókészlet feltöltése a GitHubon →

Ehhez egy (ingyenes) GitHub-fiók szükséges. A CSV formátum: nyelv1,nyelv2,csoport, opcionálisan egy negyedik, példamondat-oszloppal — lásd a részletes leírást.

The button takes you to GitHub's own upload interface, restricted specifically to this custom-word-lists folder — it can't write anywhere else in the repo. Your file arrives as a Pull Request, which the developer reviews before it shows up here among the downloadable ones.

Upload a word list on GitHub →

This requires a (free) GitHub account. CSV format: language1,language2,group, with an optional fourth column for an example sentence — see the full format description.
